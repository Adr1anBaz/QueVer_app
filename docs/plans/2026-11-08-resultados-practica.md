# Resultados esperados en la práctica

Alcance aprobado: trabajar en VS Code y mostrar qué debe ocurrir después de cada comando o acción. No cambiar la aplicación, la exposición ni el estilo general.

1. Usar la terminal integrada de VS Code y una carpeta de trabajo estable para conservar las variables de sesión.
2. Añadir resultado esperado y siguiente paso si falla a todos los bloques de Terminal. Separar los ejemplos de salida del código copiable; aclarar que versiones, rutas y tiempos pueden variar.
3. Precisar Device Manager desde la bienvenida y desde un proyecto abierto; añadir resultados visibles al iniciar el emulador, abrir archivos y guardar cambios.
4. Conservar las seis fases y sus pruebas. Comprobar copia, navegación, móvil y PDF; publicar en gh-pages.

Verificación: las pruebas web exigirán resultado y ayuda en cada bloque, encabezado de VS Code y copia exclusiva del comando. No hacen falta nuevas pruebas Android: no cambia ningún checkpoint.
