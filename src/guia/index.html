Antes de empezar

Necesitas Android Studio, un emulador configurado, internet y VS Code. Usa el emulador que ya tienes. No hace falta un teléfono ni instalar Xcode.

Comprueba que puedes instalar programas en la Mac y solicita tu clave OMDb antes de la clase. La primera compilación descarga dependencias y puede tardar.

Solicita tu clave de películas

  1. Abre OMDb · API Key. Elige la opción gratuita disponible, escribe tu correo y completa el formulario.
  2. Revisa tu correo y spam. Abre el enlace de activación que envía OMDb.
  3. Conserva tu clave. En la fase 1 la pondrás en www/js/config.local.js. No la pegues en el chat, GitHub ni capturas.
  4. Si el correo no llega, puedes completar la pantalla y SQLite mientras esperas; para buscar películas sí necesitarás activarla.

En cada fase

  1. Abre la fase que indique el expositor.
  2. Crea los archivos nuevos. En los que cambian, reemplaza todo el contenido.
  3. En VS Code: abre el archivo → ⌘A → ⌘V → ⌘S.
  4. Las líneas violetas con + muestran qué cambió. El botón copia el archivo completo, sin marcas.
  5. Ejecuta la app y haz la prueba de esa fase.

Si te atrasas, usa los archivos de la fase actual. Conserva tu clave y no desinstales la app.

Qué hace cada archivoindex.html: pantalla. index.css: estilos. index.js: acciones. db.js: consultas SQLite. Todos están dentro de www/; Cordova los incluye en la app Android.

Preparar la Mac

Abre Terminal desde Spotlight y consulta las versiones. Si aparece command not found, instala esa herramienta.

Terminal · puedes ejecutarlo desde cualquier carpeta
node --version
npm --version
/usr/libexec/java_home -V
gradle --version

Referencia del taller: Cordova CLI 13.0.0, Android 15.1.0 y SQLite 7.0.0. Node 22.9 o superior dentro de la rama 22 es una opción compatible; Node 20.17+ también sirve para estas versiones. Usa JDK 17 con Cordova, aunque Android Studio utilice otro Java.

Me falta Node o Java 17
  1. Node: descarga el instalador de la rama 22 para macOS en nodejs.org. Si la escuela administra el software, solicita autorización en lugar de cambiarlo por tu cuenta. npm viene incluido.
  2. Java: descarga Temurin JDK 17 para macOS, instalador .pkg. Apple Silicon usa aarch64; Intel usa x64. Consulta  → Acerca de esta Mac para identificarla.
  3. Termina la instalación y abre una Terminal nueva. Vuelve a consultar las versiones.

Si ya usas Homebrew y tienes permisos, Java 17 también puede instalarse con brew install --cask temurin@17. No necesitas instalar Homebrew solo para Java.

Me falta Gradle

Si brew --version funciona y tienes permiso, ejecuta:

Solo si falta Gradle y ya existe Homebrew
brew install gradle

Sin Homebrew, esta alternativa descarga Gradle 8.14.2 desde su sitio oficial y lo instala en tu usuario. Elige solo una de las dos rutas. La descarga ocupa más de 100 MB y requiere que ya hayas configurado Java 17.

Alternativa sin Homebrew · carpeta de tu usuario, sin sudo
mkdir -p "$HOME/.local/gradle"
curl -fL https://services.gradle.org/distributions/gradle-8.14.2-bin.zip -o "$HOME/.local/gradle/gradle-8.14.2-bin.zip"
unzip -n "$HOME/.local/gradle/gradle-8.14.2-bin.zip" -d "$HOME/.local/gradle"
export PATH="$HOME/.local/gradle/gradle-8.14.2/bin:$PATH"
gradle --version

Conserva esta Terminal abierta. El Gradle del sistema arranca el proceso; Cordova usa su wrapper para la versión del proyecto. No fuerces su versión editando archivos generados.

Conecta Terminal con Java y Android

En Android Studio abre Tools → SDK Manager (o More Actions → SDK Manager en la bienvenida). Confirma:

  • SDK Platforms: Android 16 / API 36 para compilar.
  • SDK Tools: Build-Tools 36.x, Platform-Tools, Command-line Tools (latest) y Android Emulator.
  • Conserva la ruta de Android SDK Location. Normalmente es ~/Library/Android/sdk.

API 36 es el SDK de compilación; no exige que tu dispositivo virtual tenga exactamente esa versión. Reutiliza el emulador existente.

Terminal · configura esta sesión; ajusta ANDROID_HOME si tu ruta es distinta
export JAVA_HOME="$(/usr/libexec/java_home -v 17)"
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/emulator:$PATH"
java -version
adb --version
sdkmanager --version

Resultado: Java indica 17 y los otros dos comandos muestran su versión. Mantén esta Terminal abierta durante la práctica. Si abres otra, vuelve a ejecutar estas variables.

Opcional: conservar las variables para futuras sesiones

Abre tu archivo ~/.zprofile en el editor; créalo si no existe. Añade al final únicamente las tres líneas export anteriores. No reemplaces su contenido. Guarda, ejecuta source ~/.zprofile y consulta java -version. Para hoy basta la configuración temporal.

Instala Cordova

Terminal · instalación de la herramienta
npm install -g cordova@13.0.0
cordova --version

npm descarga la herramienta; -g la deja disponible fuera de una carpeta particular. Espera que indique 13.0.0. Si aparece EACCES, no añadas sudo a ciegas: revisa permisos de npm.

Crear el proyecto

Ejecuta estos comandos en Terminal. Si ya existe una carpeta quever dentro de taller-cordova, usa otra ubicación.

Terminal · crear el proyecto en tu Escritorio
mkdir -p ~/Desktop/taller-cordova
cd ~/Desktop/taller-cordova
cordova create quever com.ejemplo.quever QueVer
cd quever

Qué acabamos de hacercreate genera la app. El primer quever es la carpeta; com.ejemplo.quever es el identificador Android; QueVer es el nombre visible. Para esta práctica todos pueden usarlo en emuladores separados.
Terminal · desde quever/; puede descargar dependencias
cordova platform add android@15.1.0
cordova plugin add cordova-sqlite-storage@7.0.0
cordova requirements android

Confirma que Java, SDK, target Android y Gradle aparecen disponibles. Si faltan licencias, ejecuta lo siguiente y revisa sus términos antes de aceptarlas:

Solo si hay licencias pendientes
sdkmanager --licenses

Abre Android Studio → Device Manager e inicia un solo dispositivo virtual con ▶. Espera a que muestre la pantalla de Android. No necesitas abrir el proyecto en Android Studio.

Terminal · desde quever/
cordova run android --emulator

Prueba

La app inicial de Cordova debe abrir en el emulador. Espera a que termine la primera compilación antes de continuar.

Abre Desktop/taller-cordova/quever con VS Code → File → Open Folder. Editaremos www/ y config.xml, nunca los archivos generados de platforms/android/.

Después de cada fase: guarda todos los archivos y ejecuta de nuevo cordova run android --emulator desde esta misma carpeta. No basta con refrescar una pestaña ni abrir www/index.html en Safari.

Archivos

Consultar OMDb

Añade la búsqueda y el detalle de películas. Necesitas internet y tu clave OMDb activada.

Cómo funcionaEl formulario dispara submit. searchMovies() lee el título y requestOmdb() consulta OMDb con fetch. La respuesta llega en JSON; renderSearchResults() la muestra. “Ver detalle” hace otra consulta con el identificador IMDb. Todavía no guardamos nada en SQLite.

Guardar una película

Añade las opciones “La quiero ver” y “Ya la vi”. Para las vistas, guarda también calificación y opinión.

Cómo funcionasaveMovie() reúne los datos de OMDb, el estado y tu opinión. insertMovie() los envía al plugin SQLite. Al terminar, consultamos la base y actualizamos el listado. Los ? de SQL representan valores que enviamos por separado. imdb_id es único para evitar duplicados.

Resolver errores

¿En qué carpeta ejecuto Cordova?

En la carpeta que contiene config.xml, package.json y www/. Para esta receta: cd ~/Desktop/taller-cordova/quever. Consulta pwd y ls si no estás seguro.

No reconoce node, npm o cordova / error EACCES

Abre una Terminal nueva después de instalar Node. Si npm install -g falla por permisos, no cambies permisos de todo el sistema. Puedes instalar la CLI en una carpeta de tu usuario:

Alternativa sin sudo para instalar Cordova
npm install -g --prefix "$HOME/.cordova-cli" cordova@13.0.0
export PATH="$HOME/.cordova-cli/bin:$PATH"
cordova --version

Repite el export si abres otra Terminal. Si la escuela bloquea las instalaciones, pide autorización o trabaja en pareja.

Java incorrecto o ANDROID_HOME no encontrado

Vuelve a las tres variables de Preparar la Mac, confirma la ubicación real en SDK Manager y ejecuta java -version. Debe usar 17. Después, dentro de quever, repite cordova requirements android.

Falta target Android, Build-Tools, sdkmanager o licencias

Instala API 36, Build-Tools 36.x y Command-line Tools (latest) desde SDK Manager. Si sdkmanager no aparece, revisa cmdline-tools/latest/bin dentro de tu SDK y repite las variables de sesión. Para licencias: sdkmanager --licenses, revisando sus términos.

No aparece el emulador o hay varios destinos

Abre Device Manager, inicia un solo AVD y espera a que arranque. Consulta adb devices y usa normalmente cordova run android --emulator. Si necesitas elegir uno ya encendido, copia su identificador de ADB (por ejemplo, emulator-5554) en cordova run android --emulator --target=emulator-5554, ajustándolo a tu lista. El nombre del AVD (por ejemplo, Pixel_4) no es ese identificador: puede hacer que Cordova intente arrancar otra instancia y falle por duplicado.

Gradle descarga mucho, tarda o falla

La primera ejecución descarga la distribución del proyecto y bibliotecas. Revisa que la red permita Google Maven, Maven Central y Gradle; conserva el mensaje completo del primer error. No cambies versiones dentro de platforms/android. Comprueba gradle --version y Java 17. Si el fallo es red, no se resuelve pegando otro checkpoint.

SQLite no disponible o pantalla “Preparando…”

No abras el HTML en el navegador: ejecuta la app Android. Desde quever consulta cordova plugin ls; debe incluir cordova-sqlite-storage 7.0.0. Si falta, agrégalo con cordova plugin add cordova-sqlite-storage@7.0.0 y vuelve a ejecutar. Comprueba que cordova.js, db.js e index.js están referenciados en el HTML de la fase.

La búsqueda falla o dice “Invalid API key”

Abre el enlace de activación del correo OMDb. Comprueba que www/js/config.local.js contiene una sola declaración con tu clave entre comillas y sin espacios adicionales. Guarda, recompila y busca Inception. No publiques la URL con tu clave. Un límite de cuota o una caída de OMDb no se arregla reinstalando Cordova.

Guardé archivos pero la pantalla no cambia / me atrasé

Verifica que editaste quever/www/, no platforms/android/, guarda todos los archivos y ejecuta otra vez cordova run android --emulator. Para recuperarte, copia los archivos completos de la fase actual, incluyendo los que están en “Sin cambios · recuperación”. Conserva tu clave. No desinstales ni borres quever.db.

Ver el error en la consola

Con QueVer abierto en el emulador, abre chrome://inspect/#devices en Chrome de la Mac. Pulsa “inspect” en su WebView y revisa Console. No compartas capturas con tu clave.
