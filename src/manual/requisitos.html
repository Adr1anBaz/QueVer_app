Matriz de requisitos

Información contrastada con documentación oficial el 24 de octubre de 2026. Las versiones de la CLI, de cada plataforma y del sistema operativo son cosas distintas.

Cómo leer esta tabla

“Mínimo” indica el requisito publicado para la línea de versión señalada, no una garantía de que cualquier plugin funcione. “Pendiente” señala datos que el manual no debe presentar como comprobados hasta revisarlos de nuevo.

Requisitos por capa

Versiones y herramientas separadas por responsabilidad
Capa Versión de referencia Requisitos publicados Alcance y observaciones
Cordova CLI 13.0.0 Node.js ≥ 20.17.0; npm llega con Node.js. La guía oficial publica el requisito para la familia CLI 13.x. Git es opcional y solo hace falta si npm o la CLI descargan recursos desde una URL Git.
Cordova Android 15.1.0 (publicada el 22 jul 2026) JDK 17; Android SDK; Android Studio; Gradle del sistema; variables JAVA_HOME y ANDROID_HOME. La tabla técnica vigente enumera explícitamente 15.0.x, no 15.1.x: para 15.0.x indica API 24–36, Build Tools ^36.0.0, Gradle 8.14.2, Android Gradle Plugin 8.10.1 y Node.js ≥20.17.0 o ≥22.9.0. No se debe afirmar todavía que esos valores fueron revalidados para 15.1.0.
Cordova iOS 8.1.1 (publicada el 7 jul 2026) macOS; iOS ≥13; Xcode/xcodebuild ≥15; Node.js ≥20.17.0; CocoaPods ≥1.16.0; ios-deploy ≥1.12.2. La matriz oficial aplica estos mínimos a toda la familia 8.x. Xcode incluye el SDK de iOS; sus requisitos de macOS y los SDK disponibles se consultan con Apple. iOS no puede prepararse desde Windows o Linux.

Datos que requieren cuidado

  • La guía de iOS conserva un párrafo que dice CocoaPods ≥1.8.0, pero su matriz 8.x indica ≥1.16.0. Para iOS 8.x se usará el valor de la matriz (≥1.16.0).
  • Una versión de adb o una ruta local del SDK no prueban que el SDK, Build Tools y plataforma instalados sean compatibles con Cordova Android.
  • sdk echo $ANDROID_HOME no es un comando de verificación válido; la variable se consulta por separado y su ruta depende del equipo.
  • El plugin cordova-sqlite-storage es opcional. La compatibilidad de su versión 7 con Cordova Android 15.1.0 o iOS 8.1.1 no se ha comprobado aquí.
  • Esta matriz no prueba instalaciones: no se ejecutaron Cordova, la aplicación, compilaciones, emuladores ni dispositivos.
